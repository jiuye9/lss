# 六爻起卦算法快速参考

## 一、起卦方法速查

### 方法1: 时间起卦法 (《梅花易数》)

**公式:**
```
上卦数 = (年支数 + 月数 + 日数) % 8
下卦数 = (年支数 + 月数 + 日数 + 时支数) % 8
动爻数 = (年支数 + 月数 + 日数 + 时支数) % 6
```

**地支数值:**
```
子=1  丑=2  寅=3  卯=4  辰=5  巳=6
午=7  未=8  申=9  酉=10 戌=11 亥=12
```

**八卦数值:**
```
1=乾(天)  2=兑(泽)  3=离(火)  4=震(雷)
5=巽(风)  6=坎(水)  7=艮(山)  8=坤(地)
```

**示例:**
```
日期: 2025年9月30日21时 (农历2025年8月9日亥时)
年支: 巳(6)  月日: 8+9=17  时支: 亥(12)

上卦: (6+17)=23, 23%8=7 → 艮(山) ✅
下卦: (6+17+12)=35, 35%8=3 → 离(火) ✅
动爻: 35%6=5 → 第5爻动 ✅

本卦: 山火贲
变卦: 第5爻阳变阴 → 风火家人
结果: 山火贲之风火家人
```

### 方法2: 数字起卦法

**公式:**
```
上卦数 = 第一个数字 % 8
下卦数 = 第二个数字 % 8
动爻数 = (第一个数字 + 第二个数字) % 6
```

**示例:**
```
数字: 1, 8

上卦: 1%8=1 → 乾(天) ✅
下卦: 8%8=8 → 坤(地) ✅
动爻: (1+8)%6=3 → 第3爻动 ✅

本卦: 天地否
变卦: 第3爻阴变阳 → 天山遁
结果: 天地否之天山遁
```

---

### 方法3: 铜钱起卦法

**规则:**
```
三枚铜钱,字为正面,背为反面:
- 三个正面(●●●): 老阳,记作"○"(阳爻动)
- 两正一反(●●○): 少阴,记作"——"(阴爻静)
- 两反一正(○○●): 少阳,记作"—"(阳爻静)
- 三个反面(○○○): 老阴,记作"×"(阴爻动)
```

**起卦步骤:**
```
摇六次,从下往上记录:
第1次 → 初爻
第2次 → 二爻
第3次 → 三爻
第4次 → 四爻
第5次 → 五爻
第6次 → 上爻
```

```

示例:

坤卦 000 = 阴阴阴 ☷
离卦 101 = 阳阴阳 ⚎
坎卦 010 = 阴阳阴 ⚋
```

## 五、世应定位法 (《卜筮正宗》)

### 世应口诀

> "天同二世天变五,地同四世地变初,
> 人同游魂人变归,纯卦六世三世异"

### 口诀解析

**比较上下卦的三个爻:**
- 天爻 = 上卦的上爻 vs 下卦的上爻
- 人爻 = 上卦的中爻 vs 下卦的中爻
- 地爻 = 上卦的初爻 vs 下卦的初爻

**世爻位置判断:**

| 情况 | 相同位数 | 世爻位置 | 卦例 |
|-----|---------|---------|------|
| 纯卦 | 3 | 六爻 | 乾为天、坤为地 |
| 天同 | 1(天) | 二爻 | 天风姤 |
| 地同 | 1(地) | 四爻 | 风地观 |
| 人同(游魂) | 1(人) | 四爻 | 天泽履 |
| 天变 | 2(地人) | 五爻 | 泽天夬 |
| 地变 | 2(天人) | 初爻 | 地天泰 |
| 人变(归魂) | 2(天地) | 三爻 | 火地晋 |
| 三世异 | 0 | 三爻 | 天地否 |

**应爻位置:** 世爻+3(循环),例如世爻在第2爻,应爻在第5爻

## 六、六亲装法

### 六亲口诀

> "生我者父母,我生者子孙,
> 克我者官鬼,我克者妻财,
> 同我者兄弟"

### 五行生克关系

**相生:** 木→火→土→金→水→木
**相克:** 木克土, 土克水, 水克火, 火克金, 金克木

### 六亲配置步骤

1. 确定卦宫五行(以本宫纯卦的五行为准)
2. 根据纳甲确定每爻的地支五行
3. 比较卦宫五行与爻的五行,确定六亲

**示例:** 乾宫(金)卦的六亲

| 爻的地支 | 五行 | 与金的关系 | 六亲 |
|---------|------|----------|------|
| 子 | 水 | 金生水 | 子孙 |
| 寅 | 木 | 金克木 | 妻财 |
| 辰 | 土 | 土生金 | 父母 |
| 午 | 火 | 火克金 | 官鬼 |
| 申 | 金 | 金金比 | 兄弟 |
| 酉 | 金 | 金金比 | 兄弟 |

## 九、完整装卦示例

**卦例:** 火天大有(离上乾下)

**起卦信息:**
- 方法: 指定卦
- 上卦: 离(火)
- 下卦: 乾(天)
- 动爻: 初爻

**装卦步骤:**

### 1. 确定本卦

```
上卦离(101) + 下卦乾(111) = 火天大有
```

### 2. 计算世应

```
离: 101
乾: 111
比较: 天同(1=1), 人异(0≠1), 地异(1≠1)
相同位数: 1(天同) → 二世(错误?)

实际应该是: 归魂卦 → 三世
```

### 3. 配纳甲

```
乾卦(下): 初子 二寅 三辰
离卦(上): 四酉 五未 六巳
```

### 4. 配六亲 (乾宫金)

```
初爻子(水) → 金生水 → 子孙
二爻寅(木) → 金克木 → 妻财
三爻辰(土) → 土生金 → 父母
四爻酉(金) → 金金比 → 兄弟
五爻未(土) → 土生金 → 父母
六爻巳(火) → 火克金 → 官鬼
```

### 5. 配六神 (假设甲日)

```
初爻: 青龙
二爻: 朱雀
三爻: 勾陈
四爻: 腾蛇
五爻: 白虎
六爻: 玄武
```

### 6. 生成变卦

```
初爻阳变阴: 乾(111) → 巽(011)
上卦不变: 离(101)
变卦: 离上巽下 = 火风鼎
```

### 7. 完整排盘

```
火天大有 之 火风鼎

六爻: ● 巳 官鬼 离火 玄武
五爻: ● 未 父母 离火 白虎
四爻: ● 酉 兄弟 离火 腾蛇 世
三爻: ● 辰 父母 乾金 勾陈
二爻: ● 寅 妻财 乾金 朱雀
初爻: ○ 子 子孙 乾金 青龙 应

卦宫: 乾宫
世爻: 第四爻(官鬼酉金)
应爻: 初爻(子孙子水,动爻)
变爻: 初爻子水动化巽木
```

## 十一、常见问题

### Q1: 余数为0怎么办?

**A:** 8除余0视为8,6除余0视为6
```java
int guaNum = total % 8;
if (guaNum == 0) guaNum = 8;

int yaoNum = total % 6;
if (yaoNum == 0) yaoNum = 6;
```

### Q2: 如何判断阴阳爻?

**A:**
- 阳爻(—): 二进制中的1
- 阴爻(- -): 二进制中的0
- 老阳(○): 阳爻动,将变为阴爻
- 老阴(×): 阴爻动,将变为阳爻

### Q3: 世应相差几爻?

**A:** 世爻和应爻始终相差3爻(隔两爻相对)
```java
应爻 = (世爻 + 3 - 1) % 6 + 1
```

### Q4: 如何确定卦宫?

**A:** 查八宫归属表,看本卦属于哪一宫的8卦之一
