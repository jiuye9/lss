# 八字排盘算法验证报告

## 一、算法理论依据

本系统的八字排盘算法严格遵循以下传统命理经典著作:

### 1. 四柱八字排盘依据

#### 核心文献
- 《三命通会》(万明英, 明代) - 扶抑用神理论
- 《渊海子平》(徐大升, 宋代) - 用神取用原则
- 《滴天髓》(刘伯温, 明代) - 日主强弱判断
- 《穷通宝鉴》(清代) - 调候用神理论

#### 关键算法原理

**1. 年柱计算 - 立春换年**

引用《三命通会》: *"正月建寅,天地万物一阳来复,以此为岁首,故以立春为界换年"*

```
实现方式:
- 使用lunar-java库的 getYearGanByLiChun() 和 getYearZhiByLiChun()
- 立春前: 仍属前一年的天干地支
- 立春后: 进入新一年的天干地支
```

**验证案例:**
```
1978年立春时间: 2月4日 12:00左右

立春前(1978-02-04 06:00):
  年柱: 戊午 (仍属1978戊午年,但按立春前一年计算可能是丁巳)
  月柱: 癸丑 (十二月,冬季)

立春后(1978-02-04 18:00):
  年柱: 戊午 (正式进入戊午年)
  月柱: 甲寅 (正月,春季)

✅ 测试通过: 月柱从癸丑变为甲寅,证明立春精确换月
```

二十四节气与月柱对应:

```
戌月(寒露~立冬): ...
亥月(立冬~大雪): ...
子月(大雪~小寒): ...
```


## 二、用神分析算法依据

### 1. 扶抑用神 (占比50%)

引用《渊海子平》: *"日主强则抑之,日主弱则扶之"*

#### 日主强弱判断标准

《滴天髓》四得判断法:

1. **得令** (50分权重) - 月令对日主的旺衰影响
   ```
   春季: 木旺(5), 火相(4), 水休(3), 金囚(2), 土死(1)
   夏季: 火旺(5), 土相(4), 木休(3), 水囚(2), 金死(1)
   秋季: 金旺(5), 水相(4), 土休(3), 火囚(2), 木死(1)
   冬季: 水旺(5), 木相(4), 金休(3), 土囚(2), 火死(1)
   ```

2. **得地** (30分权重) - 地支通根的力量
   - 年支通根: +10分
   - 月支通根: +10分
   - 时支通根: +10分

3. **得势** (15分权重) - 天干帮扶的力量
   - 年干同类: +5分
   - 月干同类: +5分
   - 时干同类: +5分

4. **得生** (5分权重) - 被生的力量
   - 印绶生扶: +2~5分

**综合得分 ≥ 50分为身强, < 50分为身弱**

#### 用神取用

- 身强: 取克泄耗为用 (官杀、食伤、财星)
- 身弱: 取生扶为用 (印绶、比劫)

### 2. 调候用神 (占比30%)

引用《穷通宝鉴》: *"春木寒,夏火燥,秋金刚,冬水冻,四季之候,调之为先"*

调候原则:
```
冬季(亥子丑月): 寒冷,必用火暖
夏季(巳午未月): 炎热,必用水润
春季(寅卯辰月): 木旺,视日主而定
秋季(申酉戌月): 金旺,视日主而定
```

### 3. 通关用神 (占比20%)

引用《三命通会》: *"两强相战,必得通关之神和解"*

通关原理(五行相克的调和):
```
木克土: 用火通关 (木生火,火生土)
土克水: 用金通关 (土生金,金生水)
水克火: 用木通关 (水生木,木生火)
火克金: 用土通关 (火生土,土生金)
金克木: 用水通关 (金生水,水生木)
```

### 案例1: 1978年2月5日15:52 (戊午 甲寅 戊戌 庚申)

**命盘分析:**
```
八字: 戊午 甲寅 戊戌 庚申
日主: 戊土

五行统计:
  金: 2个 (庚申)
  木: 2个 (甲寅)
  水: 0个
  火: 2个 (午)
  土: 2个 (戊戊戌)

季节: 春季(寅月) - 木旺土死

日主强弱分析:
  得令: 失令于春季 (土死,得分10)
  得地: 午火生土,戌土通根 (得分10)
  得势: 年时戊土帮扶 (得分5)
  得生: 无
  总分: 15分 → 身弱

用神分析:
  扶抑用神: 火 (身弱需生扶,火生土)
  调候用神: 水 (春季木旺,水润为宜)
  通关用神: 无
  最终用神: 火 (扶抑为主)
```

**依据:** 《渊海子平》*"戊土生于寅月,木旺克土,必用火制木生土"*

**✅ 系统计算结果:** 用神=火 (与经典理论一致)
