# 用神算法快速参考

## 🎯 核心原则

```
先看月令,次看格局
强则抑之,弱则扶之
寒暖燥湿,不可不调
五行相战,贵在通关
```

---

## 📊 日主强弱速查表

### 评分标准 (总分100)

| 项目 | 权重 | 评分方法 |
|------|------|---------|
| 得令 | 50分 | 旺(50) 相(40) 休(30) 囚(20) 死(10) |
| 得地 | 30分 | 每个通根+10,最多30 |
| 得势 | 15分 | 每个帮扶+5,最多15 |
| 得生 | 5分 | 每个生我+2,最多5 |

**判定**: 总分≥50为身强,<50为身弱

## 🔗 通关用神速查

| 冲突类型 | 通关用神 | 路径 |
|---------|---------|------|
| 木克土 | 火 | 木→火→土 |
| 土克水 | 金 | 土→金→水 |
| 水克火 | 木 | 水→木→火 |
| 火克金 | 土 | 火→土→金 |
| 金克木 | 水 | 金→水→木 |

## 🎲 综合决策流程

```
1. 判断季节
   ↓
2. 是冬或夏?
   ├─ 是 → 调候用神 (30%权重)
   └─ 否 → 下一步
   ↓
3. 五行冲突?
   ├─ 是 → 通关用神 (20%权重)
   └─ 否 → 下一步
   ↓
4. 扶抑用神 (50%权重)
   ↓
5. 确定用神
```

## 💡 实战案例

### 案例1: 1978年2月5日15:52

```
八字: 戊午 甲寅 戊戌 庚申
日主: 戊土
月令: 寅 (春季)

评分:
- 得令: 土死于春 = 10分
- 得地: 戌土通根 = 10分
- 得势: 无 = 0分
- 得生: 午火 = 5分
总分: 25分 → 身弱

扶抑: 火(生我) → 用神
调候: 水(春季)
通关: 无

最终: 火 (扶抑优先)
```

### 案例2: 1990年6月15日14:00

```
八字: 庚午 壬午 辛亥 乙未
日主: 辛金
月令: 午 (夏季)

评分:
- 得令: 金死于夏 = 10分
- 得地: 无 = 0分
- 得势: 庚金帮扶 = 5分
总分: 15分 → 身弱

扶抑: 土(生我)
调候: 水(夏季必用) → 用神
通关: 无

最终: 水 (夏季调候优先)
```

## 📝 注意事项

### ✅ 适用场景

- 普通格局八字
- 四季用神判断
- 日主强弱分析
- 喜忌神确定

### ⚠️ 特殊情况

- **从格** (从强、从弱、从财等) - 需特殊处理
- **化格** (化气格) - 需特殊处理
- **专旺格** - 需特殊处理
- **外格** - 不适用此算法
