# 八字排盘算法快速参考

## 一、四柱计算核心API

### Lunar-Java / Lunar-JavaScript 关键方法

```java
// === 年柱计算 (立春精确换年) ===
lunar.getYearGanByLiChun()   // 立春换年的年干
lunar.getYearZhiByLiChun()   // 立春换年的年支
// 口诀: "立春换年柱,不论正月初一"

// === 月柱计算 (节气精确边界) ===
lunar.getMonthGanExact()     // 节气精确的月干
lunar.getMonthZhiExact()     // 节气精确的月支
// 口诀: "月以节为界,未入节气仍属前月"

// === 日柱计算 (六十甲子轮转) ===
lunar.getDayGanExact()       // 精确的日干
lunar.getDayZhiExact()       // 精确的日支
// 口诀: "日柱不换,自古至今连续排列"

// === 时柱计算 (日上起时) ===
lunar.getTimeGan()           // 时干
lunar.getTimeZhi()           // 时支
// 口诀: "甲己还加甲,乙庚丙作初,丙辛从戊起,丁壬庚子居,戊癸何方发,壬子是真途"
```

## 二、立春换年验证公式

```
if (出生时间 < 当年立春时间) {
    年柱 = 上一年干支
} else {
    年柱 = 当年干支
}
```

**实例:**
```
1978年立春: 2月4日 12:00

1978-02-04 06:00 → 丁巳年 (立春前,属上一年)
1978-02-04 18:00 → 戊午年 (立春后,属当年)
```

## 五、用神分析三步法

### 第一步: 判断日主强弱 (四得法)

```
得令 (50分): 月令旺衰 × 10
得地 (30分): 地支通根,每个10分
得势 (15分): 天干帮扶,每个5分
得生 (5分):  被生之力,每个2分

总分 ≥ 50 → 身强
总分 < 50 → 身弱
```

### 第二步: 确定三种用神

**1. 扶抑用神 (权重50%)**
```
身强 → 取克泄耗 (官杀、食伤、财星)
身弱 → 取生扶 (印绶、比劫)
```

**2. 调候用神 (权重30%)**
```
冬季 (亥子丑) → 必用火暖
夏季 (巳午未) → 必用水润
春季 (寅卯辰) → 视日主而定
秋季 (申酉戌) → 视日主而定
```

**3. 通关用神 (权重20%)**
```
木克土 → 用火通关
土克水 → 用金通关
水克火 → 用木通关
火克金 → 用土通关
金克木 → 用水通关
```

### 第三步: 综合判定最终用神

```
优先级1: 冬夏季节 → 调候用神优先
优先级2: 五行相战 → 通关用神优先
优先级3: 正常情况 → 扶抑用神为主
```

## 七、常见错误与纠正

### ❌ 错误1: 用公历1月1日换年
```
错误: 1978年1月15日 → 戊午年
正确: 1978年1月15日 → 丁巳年 (立春未到)
```

### ❌ 错误2: 用公历月份换月柱
```
错误: 3月10日 → 卯月
正确: 需查节气,若惊蛰前仍属寅月
```

### ❌ 错误3: 时柱按24小时起
```
错误: 0点开始算子时
正确: 23点开始算子时 (早子时)
```

### ❌ 错误4: 简化用神为五行相生
```
错误: 日主木,用神就是水
正确: 需综合强弱、调候、通关判断
```

## 九、代码实现示例

### Node.js

```javascript
const { Lunar, Solar } = require('lunar-javascript');

// 公历输入
const solar = Solar.fromYmdHms(1978, 2, 5, 15, 52, 0);
const lunar = solar.getLunar();

// 四柱
const yearPillar = lunar.getYearGanByLiChun() + lunar.getYearZhiByLiChun();
const monthPillar = lunar.getMonthGanExact() + lunar.getMonthZhiExact();
const dayPillar = lunar.getDayGanExact() + lunar.getDayZhiExact();
const hourPillar = lunar.getTimeGan() + lunar.getTimeZhi();

console.log(`${yearPillar} ${monthPillar} ${dayPillar} ${hourPillar}`);
// 输出: 戊午 甲寅 戊戌 庚申
```

### Java

```java
import com.nlf.calendar.Lunar;
import com.nlf.calendar.Solar;

Solar solar = Solar.fromYmdHms(1978, 2, 5, 15, 52, 0);
Lunar lunar = solar.getLunar();

String yearPillar = lunar.getYearGanByLiChun() + lunar.getYearZhiByLiChun();
String monthPillar = lunar.getMonthGanExact() + lunar.getMonthZhiExact();
String dayPillar = lunar.getDayGanExact() + lunar.getDayZhiExact();
String hourPillar = lunar.getTimeGan() + lunar.getTimeZhi();

System.out.println(yearPillar + " " + monthPillar + " " + dayPillar + " " + hourPillar);
// 输出: 戊午 甲寅 戊戌 庚申
```
