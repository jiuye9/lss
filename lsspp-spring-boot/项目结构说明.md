## 🏗️ 模块说明

### 1. 应用启动模块 (`application/`)
- **LssppApplication.java**: Spring Boot主启动类，系统入口

### 2. 系统配置模块 (`config/`)
- **OpenApiConfig.java**: Swagger/OpenAPI配置，API文档生成
- **SecurityConfig.java**: 安全配置，认证授权规则
- **DatabaseConfig.java**: 数据库连接和事务配置
- **CorsConfig.java**: 跨域资源共享配置

### 3. 公共模块 (`common/`)
- **dto/**: 统一的数据传输对象，API响应格式
- **exception/**: 全局异常处理，统一错误响应
- **util/**: 通用工具类，日期、字符串、验证等

### 4. 认证授权模块 (`auth/`)
- **JWT认证**: 基于Token的无状态认证
- **角色权限**: RBAC权限控制模型
- **安全防护**: 防护SQL注入、XSS等攻击

### 5. 用户模块 (`user/`)
- **实体管理**: 用户、角色、权限实体
- **用户服务**: 注册、登录、信息管理
- **权限控制**: 基于角色的访问控制

### 6. 占卜核心模块 (`divination/`)

#### 6.1 八字排盘 (`bazi/`)
- **BaziCalculator.java**: 核心八字计算算法
- **LunarCalendarUtil.java**: 农历转换工具
- **算法特点**: 支持立春分界、干支纪法、五行十神

#### 6.2 六爻起卦 (`liuyao/`)
- **四种起卦法**: 时间、数字、铜钱、指定卦
- **完整体系**: 世应、纳甲、六亲、六神
- **传统算法**: 严格按照古典六爻理论

#### 6.3 紫微斗数 (`ziwei/`)
- **十二宫位**: 命宫身宫定位算法
- **星曜排布**: 主星辅星配置
- **命理分析**: 性格事业财富健康

### 7. API网关模块 (`gateway/`)
- **统一入口**: 所有API请求的统一处理
- **路由分发**: 根据请求类型分发到对应模块
- **限流熔断**: 服务保护和监控

### 8. 测试模块 (`test/`)
- **单元测试**: 算法和服务的单元测试
- **集成测试**: 端到端的API测试
- **验证测试**: 基于标准用例的算法验证

## 🚀 部署和运行

### Maven构建
```bash
cd lsspp-backend-unified
mvn clean install
mvn spring-boot:run
```

### Docker部署
```bash
docker build -t lsspp-backend .
docker-compose up -d
```

### 配置说明
- **开发环境**: application-dev.yml
- **生产环境**: application-prod.yml
- **算法配置**: config/algorithm.properties

## 📋 开发规范

### 1. 包命名规范
- 所有包都在`com.lsspp`下
- 按功能模块分层组织
- 每个模块内部按MVC分层

### 2. 类命名规范
- **Controller**: 以Controller结尾
- **Service**: 以Service结尾
- **DTO**: 以Request/Response结尾
- **Util**: 以Util结尾

### 3. 算法模块规范
- 每个占卜类型独立模块
- 算法核心类单独package
- 工具类可跨模块复用

这个结构清晰地将所有Java代码按照功能模块组织，便于维护和扩展！
