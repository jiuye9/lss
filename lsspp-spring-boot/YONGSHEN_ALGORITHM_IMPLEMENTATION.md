# 用神算法实现总结

## 📚 理论基础

本实现基于《三命通会》和《渊海子平》两部经典著作的核心理论:

### 核心口诀

1. **月令为重** - "用神多取诸月" (《三命通会》)
2. **扶抑为本** - "强者抑之,弱者扶之"
3. **调候为要** - "寒暖燥湿,不可不调"
4. **通关为妙** - "五行相战,贵在通关"

## 🎯 算法实现

### 一、日主强弱判断 (得令、得地、得势、得生)

采用**100分评分制**判断日主强弱:

#### 评分标准

| 维度 | 权重 | 满分 | 说明 |
|------|------|------|------|
| **得令** | 50% | 50分 | 月令对日主的支持 |
| **得地** | 30% | 30分 | 地支通根的支持 |
| **得势** | 15% | 15分 | 天干帮扶的支持 |
| **得生** | 5% | 5分 | 被其他五行生的支持 |

#### 得令计算 (月令旺相休囚死)

根据《渊海子平》的"旺相休囚死"理论:

- **春季** (寅卯辰): 木旺(5) 火相(4) 水休(3) 金囚(2) 土死(1)
- **夏季** (巳午未): 火旺(5) 土相(4) 木休(3) 水囚(2) 金死(1)
- **秋季** (申酉戌): 金旺(5) 水相(4) 土休(3) 火囚(2) 木死(1)
- **冬季** (亥子丑): 水旺(5) 木相(4) 金休(3) 土囚(2) 火死(1)

得令分数 = 旺相休囚死系数 × 10

#### 得地计算

地支通根加分:
- 年支通根: +10分
- 月支通根: +10分
- 时支通根: +10分
- 最高30分

#### 得势计算

天干帮扶加分:
- 年干帮扶: +5分
- 月干帮扶: +5分
- 时干帮扶: +5分
- 最高15分

#### 得生计算

被其他五行所生:
- 每个生我的天干: +2分
- 最高5分

#### 强弱判定

- **总分 >= 50**: 身强
- **总分 < 50**: 身弱

---

### 二、扶抑用神算法

根据日主强弱取用:

#### 身强者 (总分 >= 50)

取克泄耗为用:

1. **食伤** (我生者) - 优先
2. **财星** (我克者) - 次之
3. **官杀** (克我者) - 再次

**原则**: 选择八字中最弱的五行作为用神

#### 身弱者 (总分 < 50)

取生扶为用:

1. **印绶** (生我者) - 优先
2. **比劫** (同我者) - 次之

**原则**:
- 印绶不足时,优先用印
- 否则用比劫

---

### 三、调候用神算法

根据季节寒暖调节:

#### 冬季 (亥子丑月)

- **必用火暖** - 冬季寒冷,火为调候第一要务

#### 夏季 (巳午未月)

- **必用水润** - 夏季炎热,水为调候第一要务

#### 春季 (寅卯辰月)

根据日主五行:
- 金日主 → 用火 (金需火炼)
- 水日主 → 用火 (水需火暖)
- 其他 → 用水 (木火土需水润)

#### 秋季 (申酉戌月)

根据日主五行:
- 木日主 → 用水 (木需水生)
- 火日主 → 用木 (火需木生)
- 其他 → 用水 (金土需水润)

---

### 四、通关用神算法

当八字中两个最强五行存在相克时,取中间五行为通关用神:

| 冲突 | 通关用神 |
|------|---------|
| 木克土 | 火 (木→火→土) |
| 土克水 | 金 (土→金→水) |
| 水克火 | 木 (水→木→火) |
| 火克金 | 土 (火→土→金) |
| 金克木 | 水 (金→水→木) |

---

### 五、综合取用原则

#### 优先级排序

```
1. 冬夏季节 → 调候用神优先 (权重 30%)
2. 五行冲突 → 通关用神优先 (权重 20%)
3. 正常情况 → 扶抑用神为主 (权重 50%)
```

#### 决策流程

```
开始
  ↓
判断季节
  ↓
是冬或夏? ─是→ 调候用神
  │
  否
  ↓
存在五行冲突? ─是→ 通关用神
  │
  否
  ↓
扶抑用神
  ↓
确定最终用神
```
