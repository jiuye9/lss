## 核心算法实现

### 1. 时间起卦法(梅花易数农历时间法)

**理论依据**: 《梅花易数》
**算法步骤**:

```
1. 年支取数: 地支数值(子=1, 丑=2, ..., 亥=12)
2. 月日数 = 农历月 + 农历日
3. 时支取数: 地支数值
4. 上卦 = (年支数 + 月日数) % 8 (余0则为8)
5. 下卦 = (年支数 + 月日数 + 时支数) % 8 (余0则为8)
6. 动爻 = (年支数 + 月日数 + 时支数) % 6 (余0则为6)
```

**八卦数值对照**:
- 1=乾(天), 2=兑(泽), 3=离(火), 4=震(雷)
- 5=巽(风), 6=坎(水), 7=艮(山), 8=坤(地)

**测试案例**:
```
输入: 2025年10月10日 14:00
农历: 乙巳年八月十九 未时
年支: 巳=6
月日: 8+19=27
时支: 未=8
上卦: (6+27)%8=1 → 乾
下卦: (6+27+8)%8=1 → 乾
动爻: (6+27+8)%6=5
结果: 乾为天之火天大有 ✅
```

### 2. 数字起卦法

**算法步骤**:
```
1. 上卦 = 第一个数字 % 8 (余0则为8)
2. 下卦 = 第二个数字 % 8 (余0则为8)
3. 动爻 = (第一个数字 + 第二个数字) % 6 (余0则为6)
```

**测试案例**:
```
输入: 数字1, 8
上卦: 1%8=1 → 乾(天)
下卦: 8%8=8 → 坤(地)
动爻: (1+8)%6=3
结果: 天地否之天山遁 ✅
```

## 高级功能实现

### 3. 八宫卦世应定位系统

**理论依据**: 《卜筮正宗》八宫卦序理论
**实现方式**: 预置六十四卦的世应位置表

**八宫卦序规则**:
1. **本宫卦**(八纯卦): 世在上爻(第6爻)
2. **一世卦**: 世在初爻(第1爻)
3. **二世卦**: 世在二爻(第2爻)
4. **三世卦**: 世在三爻(第3爻)
5. **四世卦**: 世在四爻(第4爻)
6. **五世卦**: 世在五爻(第5爻)
7. **游魂卦**: 世在四爻(第4爻)
8. **归魂卦**: 世在三爻(第3爻)

**应爻规则**:
- 应爻与世爻相隔3爻(不是简单的世+3)
- 根据八宫卦序固定配置

**示例**:
```
乾为天(乾宫本宫卦): 世6, 应3
火天大有(乾宫归魂卦): 世3, 应6
天地否(乾宫三世卦): 世3, 应6
```

### 4. 纳甲装卦系统

**理论依据**: 《增删卜易》纳甲理论
**八卦纳甲表**:

```
乾纳甲壬: 子、寅、辰、午、申、戌(阳支顺行)
兑纳丁己: 巳、卯、丑、亥、酉、未(阴支逆行)
离纳己:   卯、丑、亥、酉、未、巳(阴支逆行)
震纳庚:   子、寅、辰、午、申、戌(阳支顺行)
巽纳辛:   丑、亥、酉、未、巳、卯(阴支逆行)
坎纳戊:   寅、辰、午、申、戌、子(阳支顺行)
艮纳丙:   辰、午、申、戌、子、寅(阳支顺行)
坤纳乙癸: 未、巳、卯、丑、亥、酉(阴支逆行)
```

**配置方式**:
1. 根据上下卦名称,从纳甲表查找对应地支
2. 下卦三爻取下卦地支0-2位
3. 上卦三爻取上卦地支3-5位

**示例(乾为天)**:
```
乾纳甲壬: [子、寅、辰、午、申、戌]
初爻: 子
二爻: 寅
三爻: 辰
四爻: 午
五爻: 申
上爻: 戌
```

### 5. 六亲配置系统

**理论依据**: 基于宫位五行与爻位五行的生克关系
**计算规则**:

```
宫位五行 vs 爻位五行:
- 相同 → 兄弟(比和)
- 我生者 → 子孙
- 我克者 → 妻财
- 生我者 → 父母
- 克我者 → 官鬼
```

**五行关系**:
- 相生: 木→火→土→金→水→木
- 相克: 木→土→水→火→金→木

**示例(乾宫卦,宫位五行=金)**:
```
爻位五行: 水、木、土、火、金、土
六亲关系:
- 水(我生者) → 子孙
- 木(我克者) → 妻财
- 土(生我者) → 父母
- 火(克我者) → 官鬼
- 金(比和)   → 兄弟
- 土(生我者) → 父母
```

### 6. 六神配置系统

**理论依据**: 日干起青龙法则
**起始六神规则**:

```
甲乙日 → 青龙
丙丁日 → 朱雀
戊日   → 勾陈
己日   → 腾蛇
庚辛日 → 白虎
壬癸日 → 玄武
```

**配置方式**:
1. 根据日干确定起始六神
2. 从初爻往上依次配置: 青龙、朱雀、勾陈、腾蛇、白虎、玄武(循环)

**示例(壬日)**:
```
日干: 壬 → 起玄武
初爻: 玄武
二爻: 青龙
三爻: 朱雀
四爻: 勾陈
五爻: 腾蛇
上爻: 白虎
```

## 变卦计算

**算法步骤**:
1. 将上下卦转为二进制(阳爻=1,阴爻=0)
2. 合并为六位二进制(下卦在前)
3. 将动爻位置的爻变换(0↔1)
4. 分离新的上下卦
5. 查表得变卦名称

**示例(乾为天第5爻动)**:
```
本卦: 111111(六个阳爻)
第5爻变: 111011(第5位变为0)
分离: 上卦=110, 下卦=111
查表: 上卦=兑, 下卦=乾 → 火天大有
```

## 技术实现细节

### 核心类: `LiuyaoCalculator.java`

**位置**: `src/main/java/com/lsspp/util/LiuyaoCalculator.java`

**关键常量**:
- `BAGUA_MAP`: 八卦数值对照(1-8)
- `DIZHI_VALUES`: 地支数值对照(1-12)
- `LIUSHISI_GUA`: 六十四卦名称表
- `BAGONG_SHIYING`: 八宫卦世应定位表(64个卦)
- `NAJIA_DIZHI`: 纳甲装卦地支表(8个卦)
- `BAGUA_WUXING`: 八卦五行属性
- `DIZHI_WUXING`: 地支五行属性

**核心方法**:
1. `timeQigua(LocalDateTime)`: 时间起卦法
2. `numberQigua(int, int)`: 数字起卦法
3. `designatedQigua(String, String, int)`: 指定卦起卦法
4. `generateCompleteGua()`: 生成完整卦象信息
5. `calculateNajiaDizhi()`: 纳甲装卦
6. `calculateLiuqin()`: 六亲配置
7. `calculateLiushen()`: 六神配置
