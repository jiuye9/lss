## 🚀 启动方式

### 方式一: Maven启动 (推荐用于开发)

```bash
cd /Users/lee/project/lsspp-spring-boot
mvn spring-boot:run
```

**优点**:
- ✅ 支持代码热重载(DevTools)
- ✅ 无需手动打包
- ✅ 适合开发调试

**缺点**:
- ⚠️ 启动稍慢(需要编译)
- ⚠️ 不适合生产环境

---

### 方式二: JAR包启动 (推荐用于生产)

#### 1. 打包应用

```bash
cd /Users/lee/project/lsspp-spring-boot
mvn clean package -DskipTests
```

#### 2. 运行JAR包

```bash
java -jar target/lsspp-backend-unified.jar
```

**自定义端口**:
```bash
java -jar target/lsspp-backend-unified.jar --server.port=8083
```

**后台运行**:
```bash
nohup java -jar target/lsspp-backend-unified.jar > logs/app.log 2>&1 &
```

**优点**:
- ✅ 启动快速
- ✅ 适合生产环境
- ✅ 易于部署

---

### 方式三: IDE启动 (推荐用于调试)

#### IntelliJ IDEA

1. 打开项目 `/Users/lee/project/lsspp-spring-boot`

## 🛑 停止服务

### Maven方式启动的服务

按 `Ctrl + C` 停止

### JAR方式后台运行的服务

```bash
# 查找进程ID
ps aux | grep lsspp-backend-unified.jar

# 停止进程
kill <PID>

# 或强制停止
kill -9 <PID>
```

### 按端口停止

```bash
# 查找占用8082端口的进程
lsof -ti:8082

# 停止该进程
kill $(lsof -ti:8082)
```

## ⚙️ 配置说明


```yaml

      cache-enabled: true
```

## 🔧 常见问题

### Q1: 端口8082已被占用

**解决方案**:

```bash
# 停止占用端口的进程
kill $(lsof -ti:8082)

# 或修改端口
java -jar target/lsspp-backend-unified.jar --server.port=8083
```

### Q2: 找不到lunar-java依赖

**解决方案**:

```bash
# 清理并重新下载依赖
mvn clean install -U
```

### Q3: 编译失败

**解决方案**:

```bash
# 清理编译缓存
mvn clean

# 跳过测试重新编译
mvn clean package -DskipTests
```
