## ⚙️ 环境配置

### API地址配置

前端已配置连接到后端API:

**开发环境** (`.env.development`):
```bash
VITE_API_BASE_URL=http://localhost:8082
VITE_APP_ENV=development
VITE_APP_DEBUG=true
```

**生产环境** (`.env.production`):
```bash
VITE_API_BASE_URL=https://your-production-api.com
VITE_APP_ENV=production
VITE_APP_DEBUG=false
```

### 修改API地址

如果后端运行在不同端口,修改 `.env.development`:
```bash
VITE_API_BASE_URL=http://localhost:8083  # 修改为实际端口
```

修改后需要重启前端服务。

## 🛑 停止服务

### 找到并停止Vite进程

```bash
# 查找Vite进程
ps aux | grep vite

# 停止进程
kill <PID>

# 或按端口停止

```

### 在运行终端按 Ctrl + C

如果是在终端中启动的服务,直接按 `Ctrl + C` 停止

## 🔧 常见问题

### Q1: 端口3000已被占用

**症状**: 启动时提示端口被占用

**解决方案**:
```bash
# 停止占用端口的进程
kill $(lsof -ti:3000)

# 或修改vite.config.ts指定其他端口
```

### Q2: API请求失败 (CORS错误)

**症状**: 浏览器控制台显示CORS错误

**解决方案**:
1. 确认后端服务运行: `curl http://localhost:8082/actuator/health`
2. 检查后端CORS配置 (已在application.yml中配置)
3. 清除浏览器缓存

### Q3: 页面空白或加载失败

**解决方案**:
```bash
# 清除依赖重新安装
rm -rf node_modules package-lock.json
npm install

# 重新启动
npm run dev
```

### Q4: HMR (热重载) 不工作

**解决方案**:
```bash
# 重启开发服务器
# Ctrl + C 停止,然后
npm run dev
```
